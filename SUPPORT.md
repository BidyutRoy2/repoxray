# Support

## Getting help

- **Usage questions:** read [docs/usage.md](docs/usage.md) first — it covers
  installation, all flags, exit codes, and how to read each finding.
- **Bugs and feature requests:** open a GitHub issue with your repoxray
  version, Python version, and a minimal reproduction.
- **CI setup:** see [docs/ci.md](docs/ci.md).

## What to include in a bug report

1. The command you ran and its full output.
2. A minimal project layout that reproduces the problem (a few small
   files are enough — never paste proprietary code).
3. What you expected vs. what you got.
